# youyou-deliberate-practice｜刻意练习

把《刻意练习》的方法转成可执行的训练流程：先看真实表现，选一个具体弱点，练习后取得反馈，修正、重试，再检查能否用于完整任务。

[English](README.md) · [版本记录](ITERATIONS.md)

## 适用场景

练了很久却没有明显进步；需要制定训练计划；想选老师、自己练、突破平台期；单项会做但实战用不出来；想把团队培训变成有反馈的技能练习。

## 11项能力

|能力|用途|
|---|---|
|练习诊断|识别目标、反馈、纠错等缺口|
|训练设计|制定有基线、动作、反馈和复测的训练单|
|心理表征|通过预测、范例对照和新情境建立判断|
|导师选择|看教学证据与个体适配，不只看名气|
|自主练习|用可靠范例完成重构、比较和修正|
|平台期诊断|找具体瓶颈，不直接加时长|
|专注管理|安排可调整的练习与休息节奏|
|动机支持|减少阻力，设置可见的小里程碑|
|工作训练|设计模拟、反馈、重演与迁移检查|
|长期成长|让投入程度与兴趣、阶段和资源匹配|
|记忆编码|练习数字分组、固定路线和可逆回忆|

一个入口按需求加载能力卡。主入口为英文，详细能力卡、术语和练习表为中文；回答遵循用户语言。

## 安装与调用

安装目录为 `~/.codex/skills/youyou-deliberate-practice`。目标不存在时可执行：

```sh
git clone https://github.com/ruoruochen/youyou-deliberate-practice.git ~/.codex/skills/youyou-deliberate-practice
```

已有安装时先比较和备份，不直接覆盖。新开一轮Codex对话后调用：

```text
$youyou-deliberate-practice 我想练口播，每天20分钟，可以录音。先帮我测基线，再设计有反馈和复测的练习。
```

不需要API密钥、付费服务、运行脚本或原书PDF。可直接使用[单次练习单](resources/practice-sheet.md)。默认在聊天中交付；用户要求保存才落盘，记录支持新增、列表/详情、编辑、归档与恢复，永久删除须明确确认。

## 来源与边界

依据安德斯·艾利克森、罗伯特·普尔著，王正林译的2016年中文版。引用页码为当时所用PDF的物理页码，可能与其他版本不同。仓库只包含方法整理、评论和有出处的短引文，不包含原书PDF、全文抽取或个人练习记录。

原中文入口与能力卡完成了22个合成场景回答、10个路由检查、2个安装路径抽检。发布版翻译入口并补齐文档，进行了结构、链接、隐私及翻译对应检查；未重新运行独立的22题评测，不能把这些检查当作真实训练效果证明。

不保证高手、冠军、涨粉或一万小时成功，不替代合格教练和医疗指导，也不代表最新研究共识。具体时长、次数、阈值是可调整的实施约定。
