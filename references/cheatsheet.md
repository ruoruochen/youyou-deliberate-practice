# 决策规则速查 — 刻意练习：如何从新手到大师

| 能力 | 一句话规则 |
|---|---|
| 诊断练习质量与适用范围 | 先区分重复、有目的练习和严格刻意练习，再修补当前缺失条件。 |
| 把目标变成单次训练闭环 | 一次盯住一个可观察的弱点，用尝试、反馈、修正和复测构成训练。 |
| 从范例中建立可用的心理表征 | 先做判断、解释依据，再与可靠范例对照，用错误修正领域内的模式。 |
| 选择能让你进步的导师 | 看导师是否能教会与你起点相近的人，并为你的具体错误设计练习。 |
| 没有导师时的范例重构训练 | 用可信范例做参照，遮答案先做，再对比纠错，而不是一边看一边照抄。 |
| 用小实验定位停滞点 | 先确认可比条件下的停滞，再用有限条件变化暴露具体弱点并复训。 |
| 按专注质量安排练习节奏 | 先减少干扰和缩短训练段，专注失效就休息，不用硬撑时长证明努力。 |
| 让练习更容易持续 | 同时减少阻力、增加继续理由，用可见的小进步和目标一致的支持维持训练。 |
| 把工作或教学改成反馈型训练 | 围绕能完成的真实技能搭建模拟、反馈和重做，而不止讲知识或开会复盘。 |
| 匹配当前成长阶段与支持 | 按兴趣、投入与表现证据匹配下一阶段的支持，不按年龄复制冠军时间表。 |
| 用分组编码和固定路线辅助回忆 | 先固定编码与检索位置，再放入新信息；回忆时沿同一路线还原并核对。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
